# Nombre del Proyecto

## Resumen ejecutivo

BananaBot es un sistema autónomo diseñado para jugar el videojuego Banana Kong en tiempo real mediante técnicas de visión por computador y automatización basada en reglas predefinidas. El proyecto surge como una oportunidad para explorar soluciones de automatización visual sin acceso a APIs internas ni modificación del videojuego, utilizando únicamente la información observable en pantalla.

La solución emplea Python, OpenCV y módulos de automatización de entradas para capturar y procesar imágenes del juego, detectar obstáculos y eventos relevantes, y ejecutar acciones automáticas como saltar, planear o descender. El sistema está compuesto por módulos de percepción, decisión y control que trabajan continuamente para reaccionar en tiempo real al entorno del videojuego.

El alcance del proyecto incluye captura y procesamiento de pantalla, detección de elementos del entorno, implementación de reglas de decisión y evaluación del desempeño del sistema. Como aporte principal, BananaBot demuestra que las técnicas clásicas de visión por computador continúan siendo eficientes y viables para resolver problemas de automatización interactiva, sirviendo además como base de comparación frente a futuros enfoques basados en inteligencia artificial y aprendizaje profundo.
